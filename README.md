# Books
- The goal of this repository is to track every book I've read and to manage my notes.

## Website
- The site uses [Zensical](https://zensical.org/) and is configured in `zensical.toml`.
- Navigation is configured in `docs/.nav.yml`.
- Pushes to `main` build and publish the site to the `gh-pages` branch through GitHub Actions. Configure GitHub Pages to use that branch.
